# Grandinių virtualūs laboratoriniai darbai (Scilab)

Šioje saugykloje laikomi interaktyvūs elektros grandinių laboratoriniai darbai, parengti darbui su Scilab 2025.1 / Windows 11.

## Turinys

- `LD1/` – 1 laboratorinis darbas: nuolatinės srovės grandinių tyrimas (v1.7).
- `LD2/` – 2 laboratorinis darbas: RC, RL ir RLC grandinių tyrimas (v2.0).
- `audits/` – LD2 nepriklausomo kryžminio audito medžiaga, naudota prieš v2.0.

## Pastaba

Studentų sugeneruotos ataskaitos ir asmens duomenys į saugyklą neįtraukiami.
